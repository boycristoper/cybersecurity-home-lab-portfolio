## Proyek yang telah dipraktikkan

### Network Monitoring Dashboard

- Menjalankan dashboard Python di Kali Linux untuk mengamati laju data masuk dan keluar, paket per detik, serta ringkasan socket TCP/UDP pada VM sendiri.
- Memverifikasi ping loopback dengan 10 dari 10 balasan tanpa kehilangan paket dan menjalankan 5 tes otomatis yang berakhir OK.

### OSINT Domain Dashboard

- Menjalankan dashboard DNS untuk menampilkan record A, AAAA, MX, NS, dan TXT dari satu domain publik beserta TTL, sumber, dan waktu pengambilan.

### Phishing Email Detector

- Menguji detektor Python pada dua email fiktif dan membandingkan indikator perbedaan domain From dan Reply-To serta kata mendesak untuk triase awal.

## Proyek dalam pembelajaran

Menyiapkan lab lokal untuk mempelajari pemeriksaan panjang, pola, dan password umum. Folder proyek tersedia di Kali; pengujian praktik belum dicatat.

Menyiapkan lab lokal untuk mempelajari konfigurasi dasar layanan web, header keamanan, dan atribut cookie. Folder proyek tersedia di Kali; pengujian praktik belum dicatat.
