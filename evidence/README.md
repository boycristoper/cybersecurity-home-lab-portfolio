# Bukti praktik pribadi

- `pcaps/`, `terminal/`, dan `screenshots/`: hasil mentah praktikmu, diabaikan Git secara default.
- `published/`: hanya bukti pilihan yang sudah kamu periksa dan siap dipublikasikan.

Saat paket ini disiapkan belum ada bukti bahwa Boy Cristoper menjalankan lab atau membuka Wireshark. Folder kosong bukan bukti pekerjaan selesai. Isi tanggal, versi aplikasi dan pengamatan sebenarnya pada laporan praktik.

Sebelum menyalin bukti ke `published/`, pastikan traffic hanya dari lab. Periksa nama akun, token, cookie, kata sandi, alamat publik dan isi jendela lain pada screenshot. Jangan unggah VM atau capture jaringan pribadi/kantor. Dataset sintetis contoh ada di `samples/`, bukan di sini.
