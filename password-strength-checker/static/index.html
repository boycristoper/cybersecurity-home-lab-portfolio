        BELAJAR DARI HASIL

        Panjang itu penting.
        Alasan tetap perlu dibaca.

        Apa arti tiga kategori hasil?

        Perlu diperbaiki: ada indikator jelas dari aturan lokal. Perlu ditinjau: panjang cukup, tetapi pola tertentu masih terdeteksi. Lolos pemeriksaan terbatas: aturan ini tidak menemukan indikator; hasil ini belum membuktikan password aman atau belum pernah bocor.

        Kenapa minimal 15 karakter?

        Angka 15 digunakan sebagai profil latihan untuk login dengan password sebagai satu-satunya faktor. Ini bukan aturan universal setiap layanan atau sertifikasi. Huruf besar, angka, dan simbol tidak diwajibkan; spasi dan Unicode diterima.

        Apa arti NFC dan daftar lokal?

        NFC menormalkan bentuk Unicode sebelum panjang dihitung sebagai code point. Satu emoji dapat memakai lebih dari satu code point. Daftar lokal hanya berisi beberapa contoh umum dan membandingkan seluruh input; ini bukan pemeriksaan basis data kebocoran.
